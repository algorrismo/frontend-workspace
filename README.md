# Frontend Workspace

A collection of weekly projects exploring frontend development and full-stack fundamentals.

## Tech stack

- **Frontend:** JavaScript, React, React Router, Next.js, Vite, HTML, CSS, and Tailwind CSS
- **Backend and data:** Node.js, Express, MongoDB, and Supabase
- **Authentication:** NextAuth.js

## What I learned

- Building reusable React components and managing state.
- Handling navigation, dynamic routes, and layouts with React Router and Next.js.
- Fetching data and using custom hooks and React Context.
- Styling applications with CSS and Tailwind CSS.
- Connecting applications to databases and building API endpoints.
- Working with authentication and protected pages.

## Weekly projects

- **week-01:** React fundamentals and component practice.
- **week-02:** React and Vite project with products, a cart, and routing.
- **week-03:** Next.js pages, layouts, and dynamic routes.
- **week-04:** Next.js and Supabase integration.
- **week-05:** Next.js application practice.
- **week-06:** Next.js with a separate Express and MongoDB backend.
- **week-07:** Next.js authentication with NextAuth.js.
